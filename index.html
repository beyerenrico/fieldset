FieldsetDigital forms you host yourself

Office staff design forms in the admin dashboard; field workers fill them in on a phone or tablet with the Field App, also offline. The server numbers each submission, renders a branded PDF and runs workflows.

Read the guidesFieldset Spec

Install Fieldset 2.1.0-rc.4pre-release

On a server or your own computer with Docker:

curl --proto '=https' --tlsv1.2 -fsSL https://github.com/beyerenrico/fieldset/releases/download/v2.1.0-rc.4/install.sh | sh -s -- --version 2.1.0-rc.4 --org "Example Ltd" --owner-email owner@example.com

The install guide covers domains, proxies, phones and mail.

  • Form builders

    Start from a template or a fillable PDF, build on a drag-and-drop canvas, preview on a phone frame and publish versions.

  • Field App, also offline

    Fill in, sign, photograph and submit on a phone or tablet. Drafts stay on the device; the outbox syncs exactly once.

  • Numbered PDFs

    The server assigns gap-free numbers and renders branded, immutable PDFs to send to the customer.

  • Workflows

    Triggers and conditions start reviews with reminders, emails and signed webhooks.

  • One command to run it

    Signed Docker images, installed, configured, backed up and upgraded with the fieldset command-line tool.

  • An open format

    Form definitions follow the open Fieldset Spec (MIT), with PHP and JavaScript SDKs.
