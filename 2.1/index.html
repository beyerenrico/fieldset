Fieldset documentation ​

Fieldset is a free, self-hostable platform for digital forms. Office staff design forms in the admin dashboard (/admin); field workers fill them in on a phone or tablet with the Field App (/app), also offline; the server numbers each submission, renders a branded PDF and runs workflows such as a review followed by an email to the customer.

These guides describe the current release. They are plain Markdown and work offline in a clone of the repository (ADR 0042, ADR 0094). Each release's guides are also published, with search and the interactive API reference, at beyerenrico.github.io/fieldset.

Terms used in these guides ​

TermMeaning
OrganizationA company using the instance. Every record belongs to exactly one organization.
Form / form versionA form definition. Publishing creates an immutable version; submissions keep the version they were filled with.
SubmissionOne filled-in form, from draft to completed. The server assigns its number on submit.
RenditionA PDF created from a submission with a design. PDFs are never changed; re-rendering creates a new one.
DesignPaper size, header, footer and layout of the PDFs, versioned like forms.
WorkflowA trigger, optional conditions and steps such as a review, an email or a webhook.
Field AppThe installable web app for phones and tablets at /app.
