# form-schema-app 0.1.0 — MVP (2026-10-17)

The first release of form-schema-app: a free, self-hostable platform where office staff design digital
forms and field workers fill them on a phone to produce branded PDF documents.

## Highlights
- **Design forms without code** — Filament form builder with templates (service report, invoice,
  inspection checklist, delivery note, timesheet, handover protocol), logic and calculations, live phone
  preview, PDF preview, versions with diff and rollback, and import of existing fillable PDFs.
- **Fill on the go** — the Field App (`/app`) for phones and tablets: signatures, photos, automatic
  saving to the server, conflict handling, gap-free document numbers, the finished PDF and "send to
  customer".
- **Documents that look like yours** — logo, colours, fonts and company details; versioned document
  designs; accessible, tagged PDFs rendered without network access; immutable renditions with hashes.
- **Automate the office** — workflows with review tasks, emails with the PDF, notifications, status
  changes and signed webhooks; a review loop with "request changes" and resubmission.
- **Open format** — the Form Schema Spec 1.0 with PHP and JavaScript SDKs (MIT) and a conformance suite.

## Install
See the README quick start: `docker compose up -d --build --wait`, then
`docker compose exec app php artisan app:install`. Configure mail in `.env` (Mailpit is included for
development). Gotenberg runs on an internal network without internet access.

## Upgrade notes
First release; no upgrade path yet. The API (`/api/v1`) and data model may change in 0.x.

## Known limitations
- Offline filling (local drafts, outbox) arrives in 0.2; the API is already prepared for it.
- No reports/exports, SSO or drag-and-drop canvas builder yet (planned for 1.0).
- Decisions waiting for human review are listed in `docs/agent/QUESTIONS.md`.
