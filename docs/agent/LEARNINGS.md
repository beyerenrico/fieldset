# LEARNINGS (gotchas; check before retrying a fix)

1. Host machine runs brew Postgres (5432), Redis (6379) and MySQL. Use Docker services on
   non-default host ports (Postgres 54329, Redis 63799, Mailpit 18025/11025, Gotenberg 13000).
2. npm `typescript@latest` is 7.0.2 (native compiler). Check typescript-eslint peer range before pinning.
3. Host tools: PHP 8.4.26 (pdo_pgsql, intl, gd, bcmath, gmp), Composer 2.8, Node 24, Docker 29,
   qpdf NOT installed on host (it lives in the queue image; tests needing it run in Docker or skip
   with a clear marker only when the binary is absent — never silently).
4. Interactive CLIs (pest --init, filament:install without flags) hang: always pass --no-interaction / write files by hand.
5. Tool output on this host is compact JSON (laravel/pao): e.g. {"tool":"pest","result":"passed",...}.
6. `Job::dispatch()` returns a PendingDispatch that dispatches on __destruct. TenantContext::run()/withoutTenant() now dispatch a returned PendingDispatch inside the tenant (guardDispatch); still prefer block closures.
7. Filament tenant association (creating hook) did not fire inside Livewire::test for the Role resource; set organization_id explicitly in actions (ManageRoles mutateDataUsing). scopedUnique() errors have no 'unique' rule key — assert on the field only.
8. Never run composer (post-autoload-dump runs filament:upgrade → view:clear) while a test run is in progress: compiled views vanish and Livewire tests fail with ViewException.
9. TypeScript 7.0 (native) is npm latest but typescript-eslint 8.71 supports <6.1: workspace pins ~6.0.3.
10. `migrate:fresh` drops tables but not PL/pgSQL functions: use CREATE OR REPLACE FUNCTION + DROP TRIGGER IF EXISTS in migrations.
11. A failing SQL statement inside RefreshDatabase's transaction aborts it (Postgres 25P02); wrap expected-to-fail raw statements in DB::transaction() (savepoint).
12. queue:work in tests stops after one job when the process exceeds --memory (default 128 MB) — pass --memory=4096 in worker tests.
13. PCOV only collects files under pcov.directory (auto = ./app) — set pcov.directory to the repo root or packages/ show 0 %.
14. `php artisan test` runs Pest in a subprocess without `php -d` ini flags (pcov.directory lost) — run coverage with vendor/bin/pest directly.
15. Livewire 4 caps dot-path depth at 10 and payloads at 1 MB (config livewire.payload); the nested Builder needs ~25 — overridden in config/livewire.php.
16. Parallel agents: use DB_DATABASE=form_schema_test_b|c php artisan test (phpunit.xml <env> does not override exported env vars).
17. Rector's LARAVEL_130 set rewrites model $fillable/$hidden into #[Fillable]/#[Hidden] attributes — edit the attribute, not a property.
18. While subagents work in the same tree, stage explicit file paths only (never `git add -A -- app resources`): it sweeps in their unfinished files.
19. qpdf `--json-key=acroform` reads `alternativename` (/TU) and `choices` (/Opt) from the widget, so pdf-lib/Acrobat fields with a separate widget kid come back with the full name and `[]`. Read /TU, /Opt, /MaxLen and /AA from the terminal field dict (nearest /T in the /Parent chain) via `--json-key=qpdf` (ADR 0024).
20. pdf-lib radio groups put option strings in /Opt and name appearance states "0", "1", …; a push button's /AP /N is a stream, not a state dict (don't read its keys as export values).
21. pdf-lib 1.17.1 cannot create signature fields or encrypt: the fixture builds the /Sig field dict by hand; encrypted fixtures come from `qpdf --encrypt` (`--deterministic-id` is refused with encryption, so regenerating changes encrypted-*.pdf bytes — restore them from git when nothing else changed).
22. Not reproducible with generated fixtures (no real Acrobat files): exact Acrobat script spellings beyond the AF* calls tested, Simplified Field Notation, JS streams with non-Flate filters, text in Type0/CID fonts or form XObjects (labels then fall back to the field name), check-box groups with distinct export values. Handled by text patterns/heuristics and covered with synthetic inputs only.
23. Storage::fake('local') wipes storage/framework/testing/disks/local in every concurrent test run; tests that hand files to an external process (qpdf) use their own fake disk name.
24. qpdf on the host: `QPDF_BINARY=scripts/qpdf` (phpunit.xml) runs a local qpdf or `docker run form-schema-app-ci qpdf` (~0.2–0.5 s per call, paths resolved with `pwd -P` because macOS /tmp is a symlink). PDF tests no longer skip (supersedes the skip note in #3); unit tests use the stored `tests/Fixtures/pdf/*.qpdf.json` dumps.
25. Filament throttles admin logins per IP (5/min, key in the cache). E2E signs admins in once in a setup project (tests/e2e/auth.setup.ts → storage/playwright-auth) and reuses the session; re-running the suite within a minute can still trip it — `docker compose exec app php artisan cache:clear` resets the limiter.
26. A sticky footer that "intercepts pointer events" in Playwright on a phone viewport was a real bug: `position: absolute` sr-only labels inside an unpositioned `overflow-x: auto` table wrapper widened the page (769 px on a 412 px phone), so the layout viewport grew and the sticky footer sat below the screen. Check `document.documentElement.scrollWidth` vs `innerWidth` first; give overflow containers `position: relative`. (Supersedes the earlier focus+Enter workaround.)
27. Livewire re-renders replace the builder preview iframe (wire:key = md5 of the definition); only `live()` fields trigger a re-render, so builder settings that the preview shows need `live(onBlur: true)`.
28. Submit runs inside the idempotency middleware's transaction (ADR 0027): queue `after_commit` is false, so anything dispatched during a submit must use `DB::afterCommit()` or `->afterCommit()`, or workers see uncommitted rows.
29. PHPStan types `Carbon::locale()` as `string|static`; use `->settings(['locale' => …])` for a localized Carbon.
30. Model strict mode (lazy-loading prevention) also bites policies called on collection items: preset relations with `setRelation()` or eager-load before authorizing each row.
31. `documents.render_on_submit` is off in testing (no Gotenberg calls from unrelated tests); tests that need renditions (send to customer, documents) must enable it.
32. Run `vendor/bin/rector --dry-run` in every gate: CI runs it and it had silently drifted on ~70 files. Skipped rules (rector.php): unused-parameter removal on policies (Gate passes args positionally), arrow-fn return types in tests (infers Pest mixin class), nullsafe coalesce (PHPStan nullsafe.neverNull).
33. The coverage container runs at base path /app: string-replacing base_path() corrupts any text containing "/app/" — anchor path stripping to path starts.
34. `workflows.complete_without_review` (submitted → completed when no workflow reviews) is off in testing like `documents.render_on_submit`; workflow tests switch it on. In Docker/local it is on, so E2E submissions without a review workflow end up `completed`.
35. Filament Builder E2E: blocks start collapsed and only expanded items render their inputs — scope locators to `.fi-fo-builder-item` filtered by the block heading; Livewire update URLs are `/livewire-<hash>/update`, not `/livewire/update`.
36. `apiHeaders()` (Sanctum::actingAs) switches the default guard to `sanctum`; a later `actingInAdmin()` in the same test then fails in Filament's TenantSet (null user) — call `auth()->shouldUse('web')` first.
37. Filament shows a disabled action with a reason only when the policy returns `Response::deny('message')` and the action has `->authorizationTooltip()`; a plain `false` hides it.
38. Status-change workflow starts are queued (StartWorkflowsForEvent, ADR 0032 amendment); with the sync queue they still run inline after commit, so tests see runs right after a submit. Mounted-action form values are not in the Livewire HTML — assert them with `assertActionDataSet()`.
36b. `SET LOCAL` outlives a released savepoint (RefreshDatabase transactions) — reset it explicitly in EXPLAIN tests.
36c. Server-side prepares: a GROUP BY that repeats a bound-parameter expression fails — group by the output alias.
39. `cache.serializable_classes` is false: cached values must be plain arrays (objects do not come back) — round-trip DTOs with toArray()/fromArray().
40. Filament widgets run `canView()` on every Livewire request (CanAuthorizeAccess boots before hydrate), not only on mount: a widget whose class stops being offered fails its next poll with 403.
41. pg_trgm GIN (1.6) also serves `=`: after adding a trigram index, "unindexed column" probes on that column get an index plan.
42. The admin panel has no custom Filament theme, so Tailwind utility classes in our own Blade views (text-gray-500, py-2, flex…) are NOT compiled and render unstyled. Use Filament components / `fi-*` classes or inline styles in custom views.
43. Filament widgets are lazy: E2E must scroll them into view before asserting their content.
44. Laravel `once()` keys the memo by the caller's file/line and the closure's `use` variables: pass the varying input (form id, user) through `use`, or every call returns the first result.
45. Strict mode throws on lazy loading only when a query returned several models — code tested with one record (e.g. one scheduled report per organization) passes and fails in production; eager-load in every loop over query results, and do not let `report($e)` hide it in tests.
46. Filament action buttons have no wire:key: two adjacent actions with complementary visible() (pin/unpin) are morphed in place by Livewire, so keyboard focus stays on the button after toggling.
47. Run E2E through `npm run e2e` (sets PLAYWRIGHT_BROWSERS_PATH=storage/playwright); plain `npx playwright test` looks in ~/Library/Caches and fails with "Executable does not exist".
48. Playwright: `browser.newContext()` inside a describe with `test.use({ storageState })` inherits that state; pass `storageState: { cookies: [], origins: [] }` for a fresh phone context.
49. Playwright: CDP `Page.crash` never answers; do not await it, wait for `page.waitForEvent('crash')`.
50. fake-indexeddb schedules with setImmediate: fake timers that fake it (`vi.useFakeTimers({ shouldAdvanceTime: true })` defaults) make Dexie throw PrematureCommitError/TransactionInactiveError. Use FAKE_TIMERS (test/utils/a-store.ts) in any test that touches the offline store.
51. Deferred focus (retries via setTimeout) must cancel once the user interacts; otherwise fast typing lands in the wrong field (renderer reveal bug, M6).
52. E2E on long repeaters: address rows by their row header ("Eintrag N"), never `.last()`; the list is virtualized above 25 rows.
53. Keycloak marks its cookies Secure even over http: the browser keeps them only on a secure context, so use `http://keycloak.localhost:8180` (Chromium treats *.localhost as secure), never an IP address.
54. In containers with `extra_hosts: keycloak.localhost:host-gateway`, PHP `dns_get_record` returns 127.0.0.1 while `gethostbynamel`/getaddrinfo returns the gateway; resolve with getaddrinfo for SSRF checks and pinning.
55. `php artisan test --parallel` / pest accept only one path argument; for a subset use `--filter` or a temporary phpunit config.
56. socialiteproviders/saml2 4.10 does not check the Audience, LightSAML's Recipient check accepts any URL, and replay detection runs before signature validation: AppSaml2Provider adds these checks (ADR 0036 amendment). Never trust a SAML package's defaults without tests for each check.
57. Vite app builds drop entry exports (`preserveEntrySignatures: false`): an entry loaded by async-alpine `x-load-src` must register its component explicitly (`Alpine.asyncData` + `import()`), see ADR 0037 amendment.
58. libcurl resolves `localhost` and `*.localhost` to loopback by itself and ignores /etc/hosts (extra_hosts): Guzzle in a container cannot reach `keycloak.localhost` unless the host is pinned with CURLOPT_RESOLVE to the getaddrinfo answer (SsrfGuardedHttpClient does this in insecure mode).
59. SortableJS clone pull (palette → list): `newDraggableIndex` counts siblings with the SOURCE list's draggable selector and is wrong for clones; compute the drop index from the item's position among the target list's cards.
60. SortableJS swap zones: a card in another list accepts a drop near its edges (outer ~32%), a card in the same list needs the central ~65%; E2E drags must approach through the neighbour card and wait for the placeholder. Filament's sticky top bar covers drag targets: scroll first and aim at the centre.
61. Tests: the app caches the sanctum guard's user between requests in one test; call `app('auth')->forgetGuards()` between bearer-token requests, or later requests reuse the first token's user.
62. E2E imports `test` from tests/e2e/support/test.ts, never '@playwright/test': it fails a test on CSP violations and uncaught page errors in app pages (also in `browser.newContext()` contexts). A context made in a beforeAll is watched with `browserProblems.watch(context)` in a beforeEach; a test that provokes an error calls `browserProblems.allow(/…/)`.
63. `php artisan tinker` in the app container needs `-e XDG_CONFIG_HOME=/tmp` (psysh cannot write /config); tests/e2e/support/platform.ts wraps it.
64. A focused sandboxed (opaque-origin) iframe is `document.activeElement` in the parent but never matches `:focus`, `:focus-visible` or `:focus-within` there (Chromium): style its focus from script (builder-v2 preview.ts sets `data-builder-preview-focused`).
65. `test.use({ ...devices['Pixel 7'] })` inside a describe fails ("defaultBrowserType forces a new worker"): drop `defaultBrowserType` from the device first. axe colour-contrast on a Filament modal right after it opens reports false failures (opacity transition): wait until `.fi-modal-window` loses `fi-transition-enter`.
66. Perf numbers on this shared host are only valid while it is quiet: parallel agents' suites push the load average to 40. `scripts/perf/*` wait for load < `PERF_QUIET_LOAD` and record it; measure images built from `git archive HEAD` + own files, not the shared tree.
67. form-schema-js evaluation must never rebuild state per row instance: `computeCalculated` once rebuilt the logic view of all rows for every row (O(rows²), 2.8 s per keystroke at 500 rows). Evaluate all instances of an element against one state, as PHP `Passes::calculations` does (M8-T05).
68. Filament tables split search terms into words by default (`splitSearchTerms`), and with bulk actions they count all matches for select-all even in simple pagination; use `splitSearchTerms(false)` + `selectCurrentPageOnly()` for expensive searches.
69. Filament's notification mailbox pulls under a per-session cache lock with `block()` (250 ms retry): parallel lazy widgets of one page view sometimes wait ~250 ms for each other. It is vendor behaviour, not a query.
70. Postgres JIT (on by default) costs ~95 ms on whole-form report aggregates (cost far above jit_above_cost): `SET LOCAL jit = off` inside a transaction for those queries. With log_min_duration_statement=0, parse/bind/execute are logged separately (counts ×3).
71. Playwright `frame.waitForFunction(..., { polling: 'raf' })` never fires in the sandboxed builder preview when the iframe is offscreen (rAF is throttled there); poll on an interval instead.
72. `composer audit` fails (exit 2) on abandoned packages too. The per-package `config.audit.ignore-abandoned` map works in Composer 2.10 (CI image, `form-schema-app-ci`) but not in the host's 2.8.12: run the audit in the CI image (`docker run --rm -v "$PWD":/app:ro -w /app form-schema-app-ci composer audit --locked`).
73. XML comments in `phpunit.xml` must not contain `--`: PHPUnit fails with `ConfigurationCannotBeBuiltException`.
74. With `defaultTestSuite="Unit,Feature"` in phpunit.xml (added for the Install suite), a new suite or test directory outside `tests/Unit` and `tests/Feature` silently never runs by default. Put new tests under those two, or add the suite to the list.
75. The Debian FrankenPHP base marks gcc/binutils/perl as manually installed, so `apt-get purge $PHPIZE_DEPS` removes almost nothing. Working recipe: `apt-mark auto '.*'`, keep required/important packages plus libraries found by an `ldd` scan of `/usr/local`, autoremove, then flatten with `FROM scratch` + `COPY --from=… / /` (2.12 GB → 648 MB, ADR 0065).
76. PGDG `postgresql-client-16` depends on `perl:any` through `postgresql-client-common` (~50 MB of perl). Docker publishes no checksums for its static CLI tarballs; pin computed hashes and cross-check the binary against the `docker:<ver>-cli` image.
77. The FrankenPHP base `HEALTHCHECK` on `:2019` always fails with `admin off`; writable XDG dirs under `/tmp` plus `persist_config off` give clean Caddy logs (R6). hadolint reports DL3006 falsely on `FROM downloads-${TARGETARCH}`.
78. Pest 5 arch: a subject array with several namespaces, or `->ignoring()` (which filters dependencies, not subjects), lets violations through. One rule per namespace; prove each rule by planting a violation once.
79. Compose `env_file` quoting: single quotes are literal; double quotes interpolate `${}` and need `\\ \" \$` escapes. `COMPOSE_DISABLE_ENV_FILE=1` ignores the project `.env` but keeps `env_file`. `docker compose config` output contains env-file secrets: never put it into command output.
80. Symfony Process: a missing binary may fork and exit 127 instead of throwing (check with `ExecutableFinder` first); a killed child makes `run()` throw `ProcessSignaledException`. `CommandStarting` is not dispatched under `runningUnitTests()`, and `Illuminate\Console\Command` already defines `context()`.
81. A PCRE `$` also matches before a trailing newline, so `"host\n"` passes `/^[a-z.]+$/`: use the `D` modifier or `\z` for every input-grammar regex.
82. valkey-cli 8.1 reads `REDISCLI_AUTH` (not `VALKEYCLI_AUTH`) and exits 0 on NOAUTH, so a healthcheck must grep for PONG. `docker compose config` prints `$` as `$$`, but containers get the literal value.
83. Postgres healthchecks should use `pg_isready -h 127.0.0.1` (TCP): over the socket, the temporary server of the first-start initialisation reports ready too early.
84. The dev `app` container has no source mount: E2E for new code needs a rebuilt image (`form-schema-app:local`). A `docker compose cp` hot-patch only applies after `docker compose restart app` (opcache never re-checks files).
85. A URL that differs only in its fragment loads nothing in a tab already on that path: pages that read a token from the fragment need a `hashchange` handler. Filament's one-time-code input submits itself after 6 digits; clicking "Sign in" afterwards races the navigation.
86. `AuditLabelsTest` finds events only through the logger method names in its regex: a new `AuditLogger` method must be added there. `toEqualCanonicalizing` on associative arrays ignores keys.
87. Docker Desktop publishes container ports only on the Mac side: `docker pull 127.0.0.1:<port>` from the daemon and `--network host` containers cannot reach them. The harness starts a host-network forwarder when a probe fails (ReleaseHarness).
88. cosign 3.1.3 has no `--tlog-upload`: offline key signing needs `--signing-config` with empty URLs, verification `--insecure-ignore-tlog`. Classic-store `docker push` re-compresses layers and changes digests; mirror exact bytes into registry:3 (with `REGISTRY_VALIDATION_MANIFESTS_INDEXES_PLATFORMS=none` for partial indexes). `docker rm -f` leaves the registry's anonymous volume behind: use `--rm` or `rm -v`.
89. SemVer: `2.0.0-alpha.1-test` sorts above every `2.0.0-alpha.N` (alphanumeric identifiers rank above numeric ones).
90. `docker cp` creates root-owned files that keep their mode: a 0700/0600 staging dir copied into a container is unreadable for a non-root image (cosign runs as 65532). Colima does not share temp dirs, so install.sh verifies via `docker create`/`cp`/`start`, not a bind mount.
91. `cosign verify-blob` accepts `-` (stdin) as the blob; a real keyless bundle verifies offline with `--trusted-root` and `--network none`. In POSIX sh, `set --` inside a function overwrites `$1` (save arguments first); shellcheck SC2015 (`a && b || c`) fails CI, group as `{ a && b; } || c`.
92. Install-suite tests do not boot Laravel (`base_path()` fails there). macOS `/var/folders` vs `/private/var`: compare paths with `pwd -P`.
