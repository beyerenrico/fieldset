# M5 Reports + dashboards: gate report (2026-10-17)

## What was built
- **Submission explorer** (§8.4, ADR 0033): one Filament page per form, with columns built from the schema keys. Keys are merged across versions; labels and options come from the newest version.
  - Money uses the currency of each version.
  - Filters cover the date range, status, submitter, group and typed field values (choices, yes/no, date, number), plus trigram search.
  - Bulk export works on a selection.
  - Visibility follows §8.6 (the view_assigned / view_own scopes).
  - Queries run on `submission_values`.
  - Default order is `submitted_at desc, uuid desc`, backed by an index.
- **Exports**: one queued job (openspout), reusing Filament's `Export` model as `ReportExport`.
  - Formats:
    - XLSX, with repeaters on a second sheet linked by number and a currency column after each money field;
    - CSV in the locale's dialect (de: `;` and decimal comma), protected against formula injection;
    - a PDF ZIP of renditions.
  - Rows come from a uuid snapshot read in chunks.
  - Limits:
    - "export all" is capped at 50,000 rows;
    - at most 2 open exports per user, and 10 requests per minute;
    - exports run on their own `exports` queue with one Horizon process.
  - When an export finishes, the user gets an `export_ready` notification (bell plus mail, with a "Herunterladen" button). A failed export sends a red notice instead.
  - Expired links answer 410 with a friendly page.
  - Filament's own download route is denied (403) because it has no tenant check.
- **Saved reports**: a form plus every explorer filter, a group-by (field, status, submitter, group, day/week/month) and a metric (count, sum, avg).
  - Sums and averages are exact decimals computed in SQL, per currency. A group that mixes currencies shows "—" with a note.
  - At most 500 groups, with a "truncated" note.
  - Shown as a table and an accessible chart, and downloadable as CSV.
  - Can be shared with the organization.
  - Scheduled mails (weekly or monthly) carry a CSV attachment; the mail period replaces a relative report period.
- **Dashboards** (§8.1, ADR 0034): widget sets derived from permissions.
  - Owner: KPIs with definitions, submissions over time per form, workflow failures.
  - Reviewer: review queue, recent submissions.
  - Designer: draft forms, recently published versions.
  - Common to all: a date-range filter in the viewer's time zone, a 60 s cache per organization and scope with a "Stand hh:mm" timestamp, and saved reports pinned per user.
- **Performance tooling**: `app:seed-load {org} {count}`, `app:dashboard-benchmark`, report and dashboard indexes (built CONCURRENTLY), and EXPLAIN-based plan tests that run the real explorer, widget and saved-report queries.

## Reviews (security, backend correctness, UX/a11y): no critical findings
| Finding | Severity | Resolution |
|---|---|---|
| Saved report form lost explorer filters on edit | high | every stored filter has a field; explorer saves through SaveReport |
| Field filters were free text and silently dropped | high | typed inputs; malformed values are form errors |
| Scheduled mails with relative periods missed the mailed period | high | mail period replaces relative periods; first mail covers the next full period |
| Scheduled mails failed for orgs with several reports (lazy loading, hidden by `report()`) | high (found while fixing) | eager loading + test |
| Money summed across currencies of different versions | medium | per-currency aggregates, "—" + note when mixed |
| Explorer order not index-backed; plan tests used simplified copies | medium | sort index, plan tests on the real queries |
| Options of older versions missing from labels/filters | medium | options merged across versions |
| PDF ZIP / exports paged with OFFSET | medium | uuid snapshot, chunks by uuid |
| Unbounded "export all", no per-user limits, exports on `default` | medium | row cap, pending + rate limits, own queue |
| Unbounded group-by | medium | 500 groups + truncated note |
| Hard-coded dates, chart without empty state/a11y, KPI meaning unclear, raw failures, wide table, dark contrast, CSV dialect, wording | low (UX) | fixed (U1–U9) |
| "Nein" matched unanswered fields; index builds blocked writes | low | answered false only; CONCURRENTLY |

Found by the E2E runs: custom admin views were unstyled because Filament has no compiled theme for arbitrary utilities, so they now use inline styles (LEARNINGS #42). Filament widgets load lazily, so the dashboard check scrolls (LEARNINGS #43).

## Deviations and known issues
- Users cannot reorder or hide dashboard widgets yet (§8.1 "later").
- KPIs can lag by up to the cache TTL (60 s); the "Stand" time shows how old they are.
- Repeater keys that collide after the 64-character cut are detected and logged (`FieldCatalog::collisions()`), not resolved.
- Text, email and hidden fields can be grouped (the 500-group cap bounds them).
- `FormExplorerTest`'s search assertion failed once in a combined subagent run and passed in every rerun; there is no known cause, so it is being watched.
