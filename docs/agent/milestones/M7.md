## SSO (ADR 0036)

Field App contract:
- `POST /auth/sso/discover` returns plain JSON (not the API envelope, like the Fortify routes).
- The IdP returns to `/app/login?sso=ok|sso_error=<code>`.
- A Fortify login refused by enforcement answers 422 `{message, errors:{sso_required:[msg]}}`.
- Error codes: sso_failed, sso_denied, account_inactive, not_member, domain_not_verified, email_unverified, provider_unavailable.

## Builder v2 (ADR 0037)
Contract: resources/builder-v2/src/contract.ts and tests/Fixtures/builder-v2/contract/*.json (orchestrator-owned). Stub page: app/Filament/Admin/Resources/Forms/Pages/CanvasBuilder.php.

**Livewire methods** (A implements, B calls; JSON travels as strings):
- `sync(string $definition, string $baseChecksum, bool $force=false): array` with `#[Json]`; `{status saved|unchanged|invalid|conflict, checksum, lint{schema_errors,findings}, savedAt}`.
- `save(...)`: same, but audited.
- `inspect(string $kind, ?string $id, string $node, string $scope): void`.
- `commitInspector(string $scope): void`; dispatches the browser event `builder-v2:node-changed` `{kind,id,node(json string)}`.
- `cloneNode(string $node, string $scopeKeys): string` with `#[Json]`.
- Actions: `$wire.mountAction('publish'|'previewPdf'|'exportDraft', {checksum})`. Publish dispatches `builder-v2:published` `{version, lockedIds}`.

**Data attributes** (B renders, E2E uses):
- `[data-builder-root]`, `[data-builder-ready]`, `data-builder-sync-state=idle|pending|saving|saved|invalid|conflict|error`
- `[data-builder-palette-item="<type>"]`, `[data-builder-page="<id>"]` with `data-builder-page-key`
- `[data-builder-list]` with `data-builder-container="pages|page:<id>|children:<id>|column:<id>:<i>"`
- `[data-builder-node="<id>"]` with `data-builder-type`, `data-builder-key`, `aria-selected`; `[data-builder-handle]`
- `[data-builder-action="move-up|move-down|move-into|move-out|move-page-prev|move-page-next|duplicate|delete|add-column|remove-column"]`
- `[data-builder-toolbar="undo|redo|save|publish|preview-pdf|export|classic|preview-toggle|json"]`
- `[data-builder-live]`, `[data-builder-lint-count]`, `[data-builder-lint-item][data-path]`, `[data-builder-inspector]`, `iframe[data-builder-preview]`
