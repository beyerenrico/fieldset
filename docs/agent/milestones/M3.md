# M3 Documents + email — gate report (2026-10-17)

## What was built
- **Branding** (page "Branding"): sniffed, re-encoded logo on the private disk, primary/accent colours
  with a live contrast warning, four bundled OFL fonts (resources/fonts, licences included), company
  details (single source; the organization profile no longer edits them).
- **Designs**: `designs` + immutable `design_versions` (DB trigger), publish/rollback (N+1)/diff/retire,
  default design per organization, Filament resource (paper, orientation, margins, header/footer rich
  text with escaped tokens, layout, repeaters, photo grid, empty fields, signature placement, watermark).
- **Rendering** (ADR 0028): canonical input → Blade + print CSS → Gotenberg (no network, JavaScript off),
  tagged PDF with real headings, `th scope`, alt texts and full locale; repeated table headers,
  `keepTogether`, no truncation; inlined assets (photos ≤ 1600 px, EXIF orientation, 25 MP limit), 25 MB
  budget; Intl formatting without floats; contrast-safe brand colours.
- **Renditions**: immutable (input_hash, file_sha256, form/design/renderer versions, page count),
  generated on submit, idempotent per request, design version pinned by the first rendition; failures
  recorded (409 `document_failed`, inbox notice, audit) and a sweep re-dispatches missing renders
  (ADR 0031); `GET /api/v1/submissions/{uuid}/document` (signed 5-minute link, visibility re-checked).
- **Builder "Preview PDF"** with sample data and the selected design.
- **Mail** (ADR 0029): per-org sender name/reply-to, optional SMTP override (encrypted, IP-pinned with
  SNI, port allow-list, password re-entry on host change), queued delivery with exactly-once claim and
  deterministic Message-ID, `mail_messages` log with retry, branded Markdown mails with a safe token
  replacer, test mail; document delivery as attachment (≤ 10 MB) or expiring link (14 days, 410).
- **Send to customer** (§9.2): `POST /api/v1/submissions/{uuid}/send` (idempotent, 202, waits for the
  PDF, caps per submission/organization), Field App dialog and document area, admin action.
- **Admin**: submissions inbox (filters, §8.6 visibility — ADR 0030, detail with pinned labels,
  attachments, events, renditions with re-render, sends), CSV member invitations, three new templates
  (delivery note, timesheet, handover protocol).

## Reviews (security, backend correctness, UX/a11y)
| Finding | Severity | Resolution |
|---|---|---|
| Render failures invisible, waiting sends hang | high | failure records, 409 `document_failed`, sweep (ADR 0031) |
| Untagged PDF; no brand-colour contrast guard | high (a11y) | tagged PDF + semantics; contrast helpers + picker warning |
| SMTP SSRF via DNS rebinding; stored password sent to a changed host | medium | IP pinning with SNI, port allow-list, password re-entry |
| Mail double send (retry race, crash after send); expired links on retry | medium | atomic claim, `sending` state, Message-ID, link refresh |
| Waiting send delivered for a voided or outdated submission | medium | gate + rendition freshness re-checked at delivery |
| Send result not announced; name not clearable; admin links expire | medium | focus/live region after close; explicit empty name; links minted on click |
| Caps, scrubbed errors, pixel limit, re-render throttle, JS off in Gotenberg, EXIF | low | implemented |
| Compact labels overflow; empty cells; photos in table repeaters; mail wording; locale formats | low | fixed |

Found during the gate itself: the dev worker could not reach Mailpit (compose), the coverage container
could not reach Gotenberg/Mailpit or extract PDF text, the CI Rector step had drifted on ~70 files
(applied, three rules skipped with reasons), and `ErrorText` corrupted texts under a short base path.

## Deviations and known issues
- Branding is not versioned (QUESTIONS #12).
- The offline send queue in the Field App is M6 scope; offline it says the send was not requested.
- Re-rendering a `changes_requested` submission path is latent until M4 (resubmit).
- CI Gotenberg service cannot take `--chromium-disable-javascript` (GitHub service containers have no
  command); compose sets it.
